# Limitations

- The root baseline comparison is present, but numeric acceptance boundaries are still provisional until a saved artifact is generated and reviewed.
- Current data posture is "real source referenced", which is below a fully normalized archival dataset package.
- The EHT shadow benchmark uses a compact GR-style shadow factor, not a full ray-traced image model.
- The internal saturation-core diagnostic uses a rescaled core radius for numerical visualization and cannot by itself establish physical singularity resolution.
- The CCBH analysis currently depends on Shen/Kormendy source files outside the repository and must remain a blocked secondary path until those upstream files are archived under `docs/data/external/...`.
- Any agreement here should be treated as exploratory black-hole benchmarking, not formal closure.
- Internal script execution does not by itself establish external replication, formal proof, or broad physical closure.
