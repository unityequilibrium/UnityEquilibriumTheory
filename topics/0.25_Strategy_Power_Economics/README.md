```text
funding sources and balance sheets
  → payments and expenditure
  → labor, capital, energy, materials, and services
  → production network
  → output, innovation, income, profit, taxes, and debt service
  → welfare, distribution, externalities, and natural-capital change
```

Standard KLEMS and input-output models are the primary benchmarks. UET-inspired variables must add information beyond those baselines; failure is retained as a valid result.
