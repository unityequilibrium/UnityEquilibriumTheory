# ทะเบียนจุดที่ทำให้ UET พังได้ (Falsification Register)

> **Topic 0.23**: หัวข้อนี้ใช้ทดสอบว่าอะไรทำให้ทฤษฎีพัง (ผู้เขียนกำหนด 2026-11-17)
> **ทฤษฎีที่ทดสอบ:** parent action ปัจจุบัน [`core/THEORY_CARD.md`](../../core/THEORY_CARD.md) (`UET_PARENT` v1) และกฎชั้น 2–3 ใน `core/engine`
> **ไม่ใช่:** Ω[C] รุ่นเก่าที่มีค่า κ, β (ดูหัวข้อ 6)
> **ระดับหลักฐาน:** ทะเบียนนี้ไม่ได้ยกระดับ claim ใด ๆ ระดับของแต่ละ claim อยู่ที่ [`docs/standard/claims.json`](../../docs/standard/claims.json)
> ร่างโดย Claude 2026-11-17 ข้อสรุปเชิงตีความในไฟล์นี้เป็น **AI interpretation**

## 1. กติกา: อะไรนับเป็น "จุดที่ทำให้พัง"

แต่ละ claim ต้องตอบสามคำถาม

1. **ถ้าเห็นอะไร ถือว่าพัง:** เงื่อนไขต้องเป็นตัวเลข และต้องเขียนลง Test Card ก่อนดูข้อมูล (STANDARD §4)
2. **ทดสอบแล้วหรือยัง:** ถ้าทดสอบแล้ว อ้างถึง result id
3. **null ก็ผ่านไหม:** null คือทฤษฎีที่รู้จักแล้วที่ใกล้ที่สุดซึ่งปิดส่วนของ UET ทั้งหมด (g_c = 0, ξ_c = 0, ไม่มีกฎชั้น 3)
   - ถ้า null ผ่านเหมือนกัน การทดสอบนั้นยังพิสูจน์ไม่ได้ว่า UET ต่างจากฟิสิกส์ที่มีอยู่
   - การทดสอบนั้นทำได้แค่สองอย่าง คือจำกัดค่าพารามิเตอร์ หรือยืนยันว่า UET ใช้แหล่งความรู้เดิมได้ถูก (UET เป็น synthesis theory)

## 3. ตัวเลขใหม่ของ wave นี้ (2026-11-17)

### 3.1 null ผ่านกี่ข้อ

- **Claim ที่ได้ L2 แล้วมี 13 ข้อ:** null ผ่านเหมือน UET ทั้ง **13 ข้อ** ผลข้อมูลจึงไม่ได้แยก UET ออกจากฟิสิกส์ที่มีอยู่เลยสักข้อ
  - สอดคล้องกับ `C_B4_DISTINCTNESS_AUDIT` ซึ่งพบว่าทุกชั้นลดรูปเป็นทฤษฎีที่รู้จักแล้ว
  - ความหมายคือ ข้อมูลยังไม่เคยเจอจุดที่ UET ต้องถูกแต่ฟิสิกส์เดิมผิด หรือกลับกัน
- **Claim ที่ทำให้พังได้จริงแล้วพัง:** 2 ข้อ
  - T015 ตัดได้แค่ lane ไม่ถึงสมการแกน
  - T018 (เพิ่ม 2026-11-17) เป็นการพังครั้งแรกที่ null ไม่พังไปด้วย ตัดขอบเขต "อายุขัยรายตัว = คลังต่อกรัม ÷ อัตราเผาผลาญ" ของกฎชั้น 3
- **Claim ที่ใกล้พังที่สุด:** T002 และ T014 (ดาวใน globular cluster) ได้ INCONCLUSIVE ทั้งคู่ z ห่างจากเส้น FAILED (z > 3) ไม่ถึง 1
- **Claim ที่โดยโครงสร้างทำให้พังไม่ได้:** 1 ข้อ (`C_R3`)

α คือความแรงของแรง portal เทียบกับแรงโน้มถ่วง ค่าในตารางมาจากการรัน producer ของ T005 และ T016 (2026-11-17) ในแต่ละระยะ λ ใช้ค่าที่แน่นที่สุด

| 3.9e-5 m ถึง 1e5 m | — | **ไม่มีข้อมูลในทะเบียนของเรา** | — |

| 1e12 m | 2.0e-19 | 5.1e-12 | T016 |

**อ่านว่า**
- ที่ระยะตั้งแต่ระดับโลกขึ้นไป การแลกเปลี่ยนผ่าน portal แรงได้ไม่เกินราว 5 ในล้านล้านส่วนของแรงโน้มถ่วง
- ช่วง 0.04 มม. ถึง 100 กม. **ยังไม่มีข้อมูลในทะเบียนของเรา** ในวรรณกรรมมีอยู่แล้ว (เช่น Eöt-Wash และการทดลองทางธรณีฟิสิกส์) แต่ยังไม่ได้ลงทะเบียนและยังไม่ได้ทำเป็น Test Card
- **อัปเดต 2026-11-17:** ลงทะเบียน Smith et al. 2000 (Eöt-Wash Rot-Wash, ประจุ = เลขแบริออน) และทำ **T019** (ผู้เขียนอนุมัติก่อนรัน, ผล PASS แบบ constraint, **L2** อนุมัติ 2026-11-17) ครอบคลุม 1 ซม. ถึง 1e5 ม.: α ≤ 6.4e-6 (g_c ≤ 1.30e-12 eV) ที่ λ ≥ 2 ม., α ≤ 2.5e-5 ที่ 10 ซม., α ≤ 0.50 ที่ 1 ซม. ช่วง 0.04 มม. ถึง 1 ซม. ยังมีแค่ α < 1 เพราะกราฟ ISL ในวรรณกรรมเป็นรูป ไม่ใช่ตาราง

## 4. จุดที่ UET อาจพังได้จริง (ผู้สมัคร ยังไม่ทดสอบ)

เรียงตามโอกาสที่ UET จะพังจริง มากไปน้อย (AI interpretation)

1. **กฎชั้น 3 ข้ามสเกล (เส้นทาง ก):**
   - เป็นจุดเดียวที่ UET พูดสิ่งที่สาขานั้นไม่ได้พูดไว้ คือการใช้ N = b τ กับระบบที่สาขาเดิมไม่ได้ใช้กฎนี้ (บริษัท เทคโนโลยี ผลิตภัณฑ์ ภาษา)
   - ในระบบพวกนี้ null คือ "จำนวนไม่ขึ้นกับอายุขัย" ซึ่งต่างจาก UET จึงพังได้จริง
   - เงื่อนไข: อัตราเกิด b และอายุขัย τ ต้องวัดแยกกันได้ และอย่าเลือกเฉพาะระบบที่รู้อยู่แล้วว่าเข้ากัน
   - **ตรวจแล้ว 2026-11-17 ([`Doc/STRESS_01_LAYER3_CROSS_SCALE.md`](Doc/STRESS_01_LAYER3_CROSS_SCALE.md)):** ในรูปปัจจุบันยังทำให้พังแบบที่ null ไม่พังไม่ได้ เพราะ N = b τ เป็น identity ในสภาวะคงตัว และ τ = F/P เป็น energetics มาตรฐานของทุกสาขา ต้องพัฒนาทฤษฎีหรือให้ผู้เขียนผูกขอบเขตก่อน
   - **ผูกขอบเขต 2026-11-17 ([`Doc/STRESS_02_LAYER3_SCOPE.md`](Doc/STRESS_02_LAYER3_SCOPE.md)):** ระบบที่มีรายรับ (เช่น บริษัท) แยกจาก null ไม่ได้ ขอบเขตเดียวที่ UET พังได้คนเดียวคือ "อายุขัยข้ามสปีชีส์ = คลังตลอดชีวิต ÷ อัตราเผาผลาญ" (rate-of-living) ผู้เขียนยืนยันว่า UET อ้างขอบเขตนี้ แล้ว **T018 ได้ FAILED** (2026-11-17) ตัดขอบเขตอายุขัยรายตัวออก แต่ไม่ได้ตัด τ = F/P ของคลังปิด และไม่ได้ตัด N = b τ
2. **T002/T014 ดาวใน globular cluster:**
   - ใกล้เส้น FAILED ที่สุด ถ้าได้ข้อมูลอิสระชุดใหม่ (เช่น cluster อื่นหรือ stellar model อื่น) ที่ทำซ้ำได้ ผลจะชี้ไปทาง PASS หรือ FAILED ชัดขึ้น
   - แต่ null ก็ผ่าน การทดสอบนี้จึงทำให้ "การใช้แหล่งความรู้" ของ UET พังได้ ไม่ใช่สมการแกน
   - **หาข้อมูลชุดใหม่แล้ว 2026-11-17: ยังไม่มีชุดที่อิสระจริง**
     - Gontcharov et al. 2026 ใช้ไปแล้วใน T014
     - Zoccali et al. 2000 ใช้ภาพ WFPC2 ชุดใกล้เคียงกับที่อยู่เบื้องหลัง T002 (Salaris et al. 2004)
     - Sandquist 2000 รวบรวมการนับจากกล้องภาคพื้นดิน ผู้เขียนเองรายงานว่า Y ≈ 0.20 ซึ่งบอกว่ามี systematic ใหญ่ ผลจึงถูกตัดสินด้วย systematic ที่รู้อยู่แล้ว
     - จึงไม่ร่าง Test Card ใหม่ ต้องรอการนับ HB/RGB จาก HST หรือ Gaia ชุดใหม่ที่มีหลาย cluster
3. **"สสารแลกเปลี่ยนกับ space" ต้องไม่เป็นศูนย์:**
   - ข้อมูลตอนนี้ยอมให้ g_c = 0 ซึ่งหมายความว่าข้อเสนอหลักของผู้เขียนรอดได้เพราะยอมให้การแลกเปลี่ยนเป็นศูนย์
   - ถ้าทฤษฎีต้องการค่าต่ำสุด (เช่น ถ้าการเขียน record ลงบน space ในชั้น 2 ต้องผ่าน ψ) ขอบเขตในหัวข้อ 3.2 อาจฆ่ามันได้
   - ต้องมี derivation ก่อนว่าชั้น 2 บังคับให้ g_c ≥ อะไร ตอนนี้ `C_R3` บอกว่า trace ลงไปที่ environment ทั่วไป ไม่จำเป็นต้องผ่าน ψ
3b. **เส้นทาง ข (ชั้น 2 ส่งผลย้อนเข้า ψ) ร่าง 2026-11-17 ([`Doc/STRESS_03_ROUTE_B_DISSIPATION_COUPLING.md`](Doc/STRESS_03_ROUTE_B_DISSIPATION_COUPLING.md)):**
   - ถ้าอัตราเผาพลังงานอิสระเป็น source ของ ψ จะได้ค่าคงที่ร่วมหนึ่งตัวคือเวลา τ_β และแรงเพิ่มขึ้นกับกำลังต่อมวล ซึ่ง null ไม่มี
   - ประมาณจาก LLR ได้ τ_β ≲ 9e15 s (ราว 3e8 ปี) ถ้าผู้เขียนกำหนดให้ τ_β ≈ 1/H₀ ผลจะใหญ่กว่าที่ LLR วัดได้หลายพันเท่า
   - ผู้เขียนไม่รู้ค่า τ_β จึงเป็นคำถามวิจัย ไม่ใช่การตัดสินของผู้เขียน ทำ **T020** (LLR, ผู้เขียนอนุมัติก่อนรัน, PASS แบบ constraint, **L2** อนุมัติ 2026-11-17): τ_β ≤ 4.6e15 s (1.46e8 ปี) ค่า τ_β = 1/H₀ จะให้ผลใหญ่กว่าที่ข้อมูลยอมราว 1e4 เท่า
3c. **ค่าขั้นต่ำของเส้นทาง ข ([`Doc/STRESS_04_ROUTE_B_MINIMUM.md`](Doc/STRESS_04_ROUTE_B_MINIMUM.md), 2026-11-17):**
