## 2. ผลของ wave ทั้งสามของ Card v2

### 2.1 V2-W4: สมการของการ์ดถูกต้อง และมี identity ของ scale symmetry

โค้ด [`uet_card_v2.py`](../../../core/03_lanes/scalar_tensor/uet_card_v2.py), test [`test_card_v2_field_equations.py`](../../../core/05_tests/physics/test_card_v2_field_equations.py) (65 test)
- สมการ dilaton, สสาร และ metric ทั้งสี่ในร่าง v2 ตรงกับ Euler–Lagrange ที่ sympy ได้จาก action โดยตรง (20 จุดสุ่มต่อสมการ, rel < 1e-10; metric ทั้งแบบไม่สม่ำเสมอและแบบ off-diagonal)
- **identity ใหม่ (ถูกทุก configuration ไม่ต้อง on shell):** φE_φ + χ·E_χ + g^μν E_μν = ½□J โดยที่ J = (1 + 6ξ_φ)φ² + (1 + 6ξ_χ)X
  เมื่อ on shell จะได้ □J = 0 คือกระแสของ scale symmetry ถูกอนุรักษ์ ถ้าเติมพจน์ที่มีมิติ (เช่นมวล χ) identity จะพังด้วยส่วนเกิน m²X พอดี (negative control)
- คำตอบที่แน่นอน: X = 0, φ = φ₀, de Sitter ที่ H² = β_eff φ₀²/(12ξ_φ), β_eff = β + α²/λ_χ ใช้ได้กับ φ₀ ทุกค่า

### 2.2 V2-EF: dilaton ไม่ต่อกับสสาร ถ้ามวลทุกตัวมาจาก field

โค้ด [`uet_card_v2_einstein.py`](../../../core/03_lanes/scalar_tensor/uet_card_v2_einstein.py), test [`test_card_v2_einstein_frame.py`](../../../core/05_tests/physics/test_card_v2_einstein_frame.py) (108 test)
- ใน Einstein frame ทิศของ dilaton (q → e^s q) เป็น Killing vector ของ field space และ potential U = V/F² ไม่ขึ้นกับ s เลย dilaton จึงไม่มีมวลและต่อกับ field อื่นผ่านอนุพันธ์เท่านั้น
- **ถ้ามวลสสารทุกตัวมาจาก field ผ่าน coupling ไร้มิติ** (มวลเป็นฟังก์ชันดีกรี 1 ของ φ, χ เช่น yφ หรือ y|χ|) scalar charge ของ dilaton เป็นศูนย์พอดี (ตรวจได้ < 1e-8) จึงได้ γ_PPN − 1 = 0 ไม่มีแรงที่ห้าระยะไกล และไม่มี DEF scalarization **สำหรับ ξ_φ ทุกค่า** ขอบ Cassini ξ ≤ 5.75e-6 ของ v1 จึงไม่ผูก v2
- **ถ้าสสารมีมวลคงที่** (คือมีพารามิเตอร์ที่มีมิติแอบอยู่) dilaton กลายเป็น Brans–Dicke ที่ α_DEF² = 2F/J → 2ξ_φ/(1 + 6ξ_φ) และ Cassini ต้องการ ξ_φ ≤ 5.75e-6 เหมือน v1 แต่ β₀ = 0 จึงไม่มี scalarization
  **สรุป: คำว่า "ไม่มีพารามิเตอร์ที่มีมิติ" ของ v2 เป็นตัวตัดสินผล Cassini**
- สเปกตรัมที่ vacuum: {0, 0, m_r²} คือ dilaton และ phase ของ O(2) ไม่มีมวล ส่วน radial mode หนัก ในลิมิต ξ → 0 ได้ m_r² F → 2αφ₀²(1 + α/λ_χ) (ความผิดพลาดลดแบบเชิงเส้นกับ ξ ตรวจ 3 ค่า)
- ระยะ Yukawa ของ mode หนัก: 0.21 fm ถ้า χ = นิวคลีออน, 1.6e-18 m ถ้า χ คล้าย Higgs **portal แบบ quartic จึงไม่ให้แรงที่ห้าในระดับที่วัดได้ในแล็บ** ขอบ g_c ของ T005, T016, T019 ไม่มีคู่ใน v2
- ข้อควรระวัง (วรรณกรรม ไม่ได้ derive): ผลนี้เป็นระดับคลาสสิก จะอยู่ในระดับควอนตัมได้ต้องใช้ regularization ที่คงตัวต่อสเกล (Shaposhnikov & Zenhäusern 2009) ไม่เช่นนั้น trace anomaly จะต่อ dilaton กับสสาร

**ผลที่ตามมาต่อเจตนาของผู้เขียน (AI interpretation):** ใน v2 "การแลกเปลี่ยนระหว่างสสารกับโครงสร้างของจักรวาล" ผ่าน portal ยังอยู่ในสมการ แต่ field ที่เบา (dilaton) มองไม่เห็นจากสสาร ส่วน field ที่ต่อกับสสารก็หนักจนระยะสั้นกว่านิวเคลียส นี่คือราคาของการผ่าน Cassini: ยิ่งมองเห็นได้ยิ่งโดนขอบเขต ชั้น 2–3 ที่เคย derive ด้วย portal แบบ trilinear ยังใช้รูปเดิมได้ เพราะเมื่อกระจาย φ = φ₀ + δφ จะได้ g_c,eff = 2αφ₀ แต่ต้องคิดใหม่ว่า δφ คือ mode ไหน

### 2.3 V2-UM: พลังงานมืดใต้ unimodular gravity มีพารามิเตอร์เดียว

โค้ด [`uet_card_v2_unimodular.py`](../../../core/03_lanes/scalar_tensor/uet_card_v2_unimodular.py), test [`test_card_v2_unimodular.py`](../../../core/05_tests/physics/test_card_v2_unimodular.py) (29 test)
- unimodular เติม Λ₀ (ค่าคงที่จากการอินทิเกรต) ใน potential ทำให้ Einstein frame ได้ U = U₀ + A e^(−λσ) โดย **λ = 4√(ξ_φ/(1 + 6ξ_φ)) < 1.633** (ตรวจกับวิธีที่สองคือเดินตาม orbit ใน field space)
- shift symmetry ทำให้ค่าเริ่มต้นของ σ แค่เปลี่ยน A และ A ถูกกำหนดโดย Ω_DE วันนี้ ถ้า U₀ = 0 **w(a) ทั้งเส้นขึ้นกับ ξ_φ ตัวเดียว** (v1 ใช้ 3 ตัว: ξ_c, ψ_i, m/H₀)
- thawing: ตรงกับสูตร Scherrer & Sen 2008 ภายใน 1% ที่ λ ≤ 0.3, ช่องว่างลดตาม λ², RK4 order 4, ΛCDM ที่ λ → 0
- ทิศของ CPL ล็อกไว้: wa/(1 + w₀) อยู่ระหว่าง −1.51 ถึง −1.28 สำหรับ ξ_φ ทุกค่า

|---|---|---|---|
| 0.0047 | 0.27 | −0.989 | −0.016 |
| 0.0158 | 0.48 | −0.965 | −0.051 |
| 0.0350 | 0.68 | −0.930 | −0.103 |
| 0.0477 | 0.77 | −0.910 | −0.132 |

ช่วง λ = 0.48–0.77 ที่วงการได้จาก CMB + DESI + SN (Bhattacharya et al. 2024) ตรงกับ ξ_φ ≈ 0.016–0.048 (แปลงตัวเลขจากวรรณกรรม ไม่ใช่การทดสอบของเรา) ตาม §16 B1 นี่คือคำตอบที่วงการมีอยู่แล้วสำหรับ exponential quintessence จึงไม่ควรร่าง Test Card ที่ทำซ้ำ เว้นแต่ผู้เขียนอยากให้ UET มีผลของตัวเอง
