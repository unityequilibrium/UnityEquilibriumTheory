## 3. 🔬 Implementation & Code (การทำงานของโค้ด)

### 3.1 Key Algorithm
1.  **Scan Directory:** อ่านไฟล์ .dat ทั้งหมดใน folder Data
2.  **Parse Header:** อ่านค่า Distance (D), Inclination (Inc), และ Luminosity (L)
