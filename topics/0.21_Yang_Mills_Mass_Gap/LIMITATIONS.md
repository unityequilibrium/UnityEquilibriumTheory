# Limitations

- The topic currently uses a best-fit style parameter sweep.
- Internal benchmark agreement does not constitute a Clay-problem proof.
- Dataset and proof packaging remain topic-local rather than independently replicated.
- The current verifier uses one scalar glueball benchmark row; it does not yet validate the
  tensor and pseudoscalar spectrum simultaneously.
- The scale factor and `alpha` sweep are calibration choices, so downstream theory claims
  must inherit that fitted-parameter limitation.
- The local data table is source-backed but not a publisher-raw extraction bundle with
  independent parsing notes.
- The diagnostic proof script is a repository sanity check and should not be cited as a
  complete constructive proof of Yang-Mills existence and mass gap.
