## แก่นประเด็นของเล่มนี้
*   **ปฐมบทวาทกรรมและโลกโบราณ (ราว 3,000 ปีก่อน ค.ศ. — ค.ศ. 1800):** เปิดตัวกล่องเครื่องมือ 3 แว่นตา (ภาษา & สมอง, อำนาจ 4 มิติ, ไดอะเลกติก) แล้วเล่าประวัติศาสตร์ของทั้งโลกคู่ขนานเป็นเส้นตรงเส้นเดียว
*   **สายธารภาษาและอำนาจ:** จากอารยัน/อินโด-ยูโรเปียน ➔ ยุคกลางคาทอลิก/ซามูไร/อยุธยา ➔ แท่นพิมพ์กูเทนเบิร์ก (1445) ➔ ยุคตื่นรู้ John Locke ➔ สหรัฐอเมริกาประกาศอิสรภาพ (1776) ขนาน ก่อตั้งรัตนโกสินทร์ (1782)
