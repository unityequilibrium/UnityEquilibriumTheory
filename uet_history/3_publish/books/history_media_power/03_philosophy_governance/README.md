## โครงสร้างโฟลเดอร์ทำงาน (Standard Book Structure)

เพื่อให้การทำงานเป็นระบบและเอเจนท์สามารถดึงข้อมูลมาเรียบเรียงได้แม่นยำ กรุณาจัดเก็บข้อมูลตามหมวดหมู่ดังนี้:

*   **`1_raw/`**: สำหรับใส่ข้อมูลดิบทั้งหมด
    *   ไฟล์ประวัติการแชท (Chat logs)
    *   ไฟล์บันทึกเสียง (Audio transcripts)
    *   บทความอ้างอิง, ข้อมูลดิบจากแหล่งภายนอก
    *   *Note: ลากไฟล์แชทหรือข้อมูลที่ยังไม่ถูกจัดระเบียบมาโยนใส่ที่นี่ได้เลย*
*   **`2_digest/`**: สำหรับข้อมูลที่ผ่านการสังเคราะห์หรือย่อยมาแล้ว (Agent จะใช้พื้นที่นี้ในการสรุปโน้ต)
    *   สรุปแก่นประเด็นของแต่ละบท
    *   สมการเชิงระบบ หรือโครงสร้างแนวคิดที่สกัดจาก `1_raw/`
*   **`ch_drafts/`**: สำหรับใช้เขียนและเก็บต้นฉบับแยกรายบท (Chapter Drafts)
    *   ตัวอย่าง: `ch_01_information_processing.md`, `ch_02_cognitive_mapping.md`
*   **`book_blueprint.md`**: โครงร่างและพิมพ์เขียวหลักของหนังสือ (แหล่งอ้างอิงโครงสร้างแบบ Master File)

## วิธีการทำงานร่วมกับ Agent
1. เมื่อคุณมีไอเดียหรือไฟล์แชทใหม่ โยนใส่ `1_raw/`
2. สั่งให้ Agent วิเคราะห์ไฟล์ใน `1_raw/` แล้วสรุปลง `2_digest/`
3. เมื่อตกผลึก สั่งให้ Agent ร่างเนื้อหาหนังสือแต่ละบทลงใน `ch_drafts/` โดยอ้างอิงโครงสร้างจาก `book_blueprint.md`
