## 1. สมการแกน

หน่วย natural (ħ = c = 1), signature (−,+,+,+), field เป็น canonical แล้ว (k, Z, ε ของ v1 ถูกดูดซับตาม §5 ของ v1), X ≡ |χ|² = χ₁² + χ₂²

```
S = ∫ d⁴x √−g [ ½ F(φ, X) R − ½ (∇φ)² − ½ (∇χ_A)² − V(φ, X) ]

F(φ, X) = ξ_φ φ² + ξ_χ X
V(φ, X) = (λ_χ/4) (X − (α/λ_χ) φ²)² + (β/4) φ⁴
```

ไม่มีพารามิเตอร์ที่มีมิติเลย การกระทำนี้คงตัวภายใต้ g → s⁻²g, φ → sφ, χ → sχ (ตรวจได้ด้วยวิธีของ S1)

**ทางเลือกที่ผู้เขียนต้องตัดสิน (ไม่ได้อยู่ในสมการข้างบน):**
- **(ก) gravity ปกติ:** พลังงานมืดเป็นค่าคงที่ใน Einstein frame β/(4ξ_φ²) (w = −1 ตรง ๆ, S1 ข้อ 2)
- **(ข) unimodular gravity** (√−g = 1) แบบ García-Bellido และคณะ 2011: ค่าคงที่จักรวาลเป็นค่าคงที่จากการอินทิเกรต และ dilaton ได้ศักย์ที่ทำให้ w₀ > −1 ได้ จึงมีพลังงานมืดแบบ thawing กลับมา
