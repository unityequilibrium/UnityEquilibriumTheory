## 6. ผลที่ derive แล้ว (ร่างที่ 2)

### 6.1 dilaton ต่อกับสสารไหม (V2-EF)

ใน Einstein frame (g_E = F g, M = 1): L_E = R_E/2 − ½K_ab ∂q^a∂q^b − U, K_ab = δ_ab/F + (3/2)F_aF_b/F², U = V/F²
- ทิศ dilaton q → e^s q เป็น Killing vector, K_ab q^b = ∂_aJ/(2F) และ U ไม่ขึ้นกับ s: dilaton ไม่มีมวล ต่อกับ field อื่นผ่านอนุพันธ์เท่านั้น
- **มวลดีกรี 1 (ข้อกำหนดใน §1):** scalar charge = 0 พอดี → γ_PPN − 1 = 0, ไม่มีแรงที่ห้าระยะไกล, ไม่มี scalarization **สำหรับ ξ_φ ทุกค่า**
- **มวลคงที่ (ละเมิดข้อกำหนด):** Brans–Dicke, α_DEF² = 2F/J → 2ξ_φ/(1+6ξ_φ), ต้อง ξ_φ ≤ 5.75e-6 (Cassini) เหมือน v1, β₀ = 0
- ระดับควอนตัม (วรรณกรรม): คงอยู่ได้ถ้าใช้ regularization ที่คงตัวต่อสเกล ไม่เช่นนั้น trace anomaly ทำให้ต่อกับสสาร

### 6.2 portal ให้แรงที่ห้าไหม (V2-EF)

- สเปกตรัมที่ vacuum (β = 0): {0, 0, m_r²}: dilaton และ phase ของ O(2) ไม่มีมวล radial mode หนัก, m_r²F → 2αφ₀²(1 + α/λ_χ) เมื่อ ξ → 0
- ระยะของ mode หนัก 0.21 fm (นิวคลีออน) หรือ 1.6e-18 m (Higgs) **ไม่มีแรงที่ห้าที่วัดได้** ขอบ g_c ของ T005, T016, T019 ไม่มีคู่ใน v2
- ราคา (AI interpretation): field ที่เบามองไม่เห็นจากสสาร field ที่มองเห็นก็หนักมาก การแลกเปลี่ยนสสาร–space ยังอยู่ในสมการ แต่ไม่มีช่องให้วัดในระยะยาว

### 6.3 พลังงานมืด (V2-UM)

- (ก): w = −1 ตรง ๆ (ΛCDM) จากเลขที่บันทึกไว้แล้วใน R_T041 ΛCDM อยู่ห่างจาก CPL Δχ² = 5.42 ซึ่งตกช่วง INCONCLUSIVE ของเกณฑ์ T041 (การอ่านเลขเดิม ไม่ใช่การทดสอบใหม่)

1. ระดับควอนตัม: dilaton ยังไม่ต่อกับสสารไหมเมื่อมี one loop (ต้องเลือก regularization)
2. การ derive ชั้น 2–3 ใหม่ด้วย mode ของ v2 (KMS, burn law) ว่า dilaton มีแรงเสียดทานในอ่างสสารผ่าน derivative coupling เท่าไร
3. การเติบโตของโครงสร้างและ CMB ภายใต้ (ข) (background เท่านั้น)
4. ค่าของ coupling ทุกตัวยังไม่ถูกทำนาย (hierarchy ยังอยู่)
