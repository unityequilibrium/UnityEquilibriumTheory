# Unity Equilibrium Theory (UET) v0.9.1

> ## 🇬🇧 [English version → README.md](README.md)
>
> ฉบับไทยกับอังกฤษมีเนื้อหาเดียวกัน แก้ไฟล์หนึ่งต้องแก้อีกไฟล์ด้วย

UET เป็นงานวิจัยที่เปลี่ยนแนวคิดเดียวให้เป็นขั้นตอนการคำนวณ:
ระบบจะคงอยู่ได้นานเท่าที่มันบริหารทรัพยากรที่ใช้ และบัญชีชุดเดียวกันควรใช้ได้กับทุกระบบ
ครอบคลุมระบบที่ซ้อนกัน (เซลล์ในสิ่งมีชีวิตในระบบนิเวศ) ทรัพยากรที่หลายระบบใช้ร่วมกัน และนับเวลาเป็นทรัพยากรด้วย

UET **ไม่ได้อ้างว่าเป็นฟิสิกส์ใหม่** แต่เป็น**ทฤษฎีสังเคราะห์**: นำผลที่ตีพิมพ์และอ้างอิงได้จากเทอร์โมไดนามิกส์ แรงโน้มถ่วง
ฟิสิกส์ระบบเปิด และนิเวศวิทยา มาต่อกันเป็นสายเหตุผลเดียว แล้วตรวจสองเรื่องในทุกขั้น:
ผลที่ยืมมาใช้ตรงตามเงื่อนไขของต้นฉบับไหม และเมื่อต่อกันแล้วยังเข้ากันได้ไหม
จากนั้นนำทุกข้ออ้างไปเทียบกับข้อมูลจริงที่ตีพิมพ์แล้ว และบันทึกผลทั้งที่ผ่านและไม่ผ่าน

## 1. สมการหลัก

UET เริ่มจากสมดุลเดียว ซึ่ง README v0.9.0 เขียนไว้ว่า

$$\Omega = C \cdot I$$

Ω คือสมดุลที่ระบบหา C คือการเชื่อมต่อหรือปฏิสัมพันธ์ และ I คือต้นทุนของการแยกตัว
ภาพนี้เก็บไว้ครบไม่ได้แก้ที่ [`docs/history/LEGACY_CLAIMS.md`](docs/history/LEGACY_CLAIMS.md)
สมการปัจจุบันทำให้มันคำนวณได้จริงในสามชั้น นิยามเต็ม ตำแหน่งโค้ด และ test อยู่ใน
[`core/THEORY_CARD.md`](core/THEORY_CARD.md) และ [`core/AUTHOR_PROPOSITION.md`](core/AUTHOR_PROPOSITION.md)

### ชั้น 1: สสารแลกพลังงานกับโครงสร้างของ space

action แม่ (หน่วย natural, signature −+++; δ = φ − φ\*, |χ|² = χ₁² + χ₂²):

$$S = \int d^4x \sqrt{-g}\Big[\tfrac{F(\varphi)}{2\kappa}(R - 2\Lambda) - \varepsilon\big(\tfrac{1}{2}k(\nabla\varphi)^2 + U(\varphi)\big) - \tfrac{1}{2}Z(\nabla\chi_A)^2 - W(|\chi|^2) + \tfrac{1}{2}\varepsilon h\,\delta\,|\chi|^2\Big]$$

$$F(\varphi) = 1 + \varepsilon\xi\delta^2,\qquad U = \rho_* + \tfrac{1}{2}\mu^2\delta^2 + \tfrac{1}{4}\lambda_\varphi\delta^4,\qquad W = \tfrac{1}{2}m^2|\chi|^2 + \tfrac{1}{4}\lambda_\chi|\chi|^4$$

| สัญลักษณ์ | ความหมาย |
|---|---|
| χ | สสาร เป็นสนาม O(2) |
| φ | สนามตอบสนองของ space ต่อกับความโค้ง R ผ่าน F(φ) |
| h | portal: เทอมเดียวที่สสารกับสนามตอบสนองแลกพลังงานกัน |
| ξ, μ, λ | รูปแบบ coupling และศักย์ของสนามตอบสนอง |

สมการของ metric สนามตอบสนอง และสสาร derive ออกมาจาก action นี้ (ตรวจแบบ symbolic แล้ว claim `C_PARENT_EOM_DERIVED`, L1)
symmetry ของ action ให้ปริมาณอนุรักษ์ครบตามทฤษฎีบทของ Noether: ประจุของสสาร (O(2)) อนุรักษ์แม้สสารแลกพลังงานกับ space, พลังงานรวมของสสาร สนามตอบสนอง และเรขาคณิตอนุรักษ์ แต่พลังงานของสสารอย่างเดียวไม่อนุรักษ์ โมเมนตัม โมเมนตัมเชิงมุม และประจุของ boost อนุรักษ์ โดยประจุ boost อนุรักษ์เพราะสนามทั้งสองมี light cone เดียวกัน (claim `C_NOETHER_COVERAGE`, L1)
สสารอย่างเดียวไม่อนุรักษ์พลังงาน แต่สสารรวมกับสนามตอบสนองอนุรักษ์

### ชั้น 2: ระบบเปิดเผาพลังงานอิสระและทิ้งร่องรอย

$$dS_{\text{sys}} = d_eS + d_iS,\quad d_iS \ge 0 \qquad P = T\,\dot S_{\text{prod}} \qquad \Sigma = I + D$$

ระบบในสิ่งแวดล้อมเสียพลังงานอิสระ F ด้วยกำลังเผา P entropy ที่มันสร้าง Σ แยกเป็นบันทึกที่อ่านกลับได้ I
กับความต่างศักย์ D (claim `C_R3_TRACE_RECORD_PLUS_POTENTIAL`, L1)
แรงเสียดทาน noise และกฎข้อ 2 เกิดขึ้นเองจากระบบปิด โดยไม่ต้องใส่เพิ่ม (claim `C_LAYER2_OPEN_FROM_CLOSED`, L1)
ถ้าให้สนามสสาร χ ของชั้น 1 เป็นแหล่งความร้อน action ของชั้น 1 เองจะให้สนาม φ มีแรงเสียดทานและ noise ที่เป็นไปตามความสัมพันธ์
fluctuation-dissipation (KMS) แรงเสียดทานจึงถูกกำหนดด้วยค่าการเชื่อม portal ไม่ได้เลือกเอง (claim `C_L2_FROM_ACTION`, L1)

### ชั้น 3: การคัดสรรด้วยการบริหารทรัพยากร

$$\tau = \int \frac{dF}{P(F)} \qquad N = b\,\tau \qquad \frac{dx_i}{dt} = x_i\,(f_i - \bar f)$$

อายุของระบบ τ มาจากทุน F และการที่กำลังเผา P ขึ้นกับทุนนั้น
จำนวนที่เห็น N เท่ากับอัตราการเกิด b คูณอายุ ในกลุ่มระบบที่สร้างตัวเองเพิ่มและใช้ทรัพยากรร่วมกัน
ระบบที่อยู่ได้ที่ระดับทรัพยากรต่ำสุด R\* ชนะ ถ้ามีทรัพยากรสองชนิดจะเกิดดุลยภาพผสมที่เสถียร
(claim `C_L3_SELECTION_FORMAL` และ `C_L3_BURN_LAW_SELECTION`, L1)

**สิ่งที่สมการยังทำไม่ได้:** ชั้น 2 derive จาก action ของชั้น 1 ได้แค่ช่องทางเดียว ส่วนชั้น 3 ได้แค่อัตราการจับทรัพยากรกับอัตราการตาย (claim `C_L3_FROM_ACTION`, L1: แหล่งที่เท่ากันทุกทิศป้อนพลังงานให้ไม่ได้ ต้องเป็นกระแสที่ไหลเร็วกว่าโหมด) อัตราการรั่วของแหล่งทรัพยากร derive ได้แล้ว แต่อัตราการเติมไม่ได้มาจาก action: ระบบอยู่รอดได้เมื่อขอบเขตส่งทรัพยากรเข้ามามากกว่า S* = δR*ₘᵢₙ (claim `C_L3_SUPPLY`, L1) ส่วนชุดโหมดยังไม่ได้ ทั้งสามชั้นจึงยังไม่เป็น action เดียว
และทั้งสามชั้นยังไม่ให้ตัวเลขที่ทฤษฎีมาตรฐานให้ไม่ได้ (หัวข้อ 3)

## 2. ตรรกะของผู้เขียน

คำของผู้เขียนเองอยู่ใน [`core/AUTHOR_PROPOSITION.md`](core/AUTHOR_PROPOSITION.md) สรุปได้ดังนี้

1. โครงสร้างที่ต้องเผาพลังงานเพื่อคงรูป (dissipative structure) ปิดตัวเองไม่ได้ ไม่อย่างนั้นกฎข้อ 2 จะทำให้มันสลาย
2. "เปิด" หมายถึงสสารแลกพลังงานกับโครงสร้างของ space ที่มันอยู่ ไม่ใช่แลกกับอะไรนอกจักรวาล
3. ไม่มีอะไรหยุดนิ่ง ทุกระบบจึงใช้พลังงานอยู่ตลอด
4. การใช้พลังงานคือพฤติกรรม ระบบที่เผาเร็วอยู่ได้สั้น ระบบที่บริหารทุนได้อยู่ได้นาน
5. ระบบที่บริหารทรัพยากรไม่ดีจะหมดและหายไป สิ่งที่เราเห็นจึงเป็นสิ่งที่ผ่านการคัดสรรด้วยการคงอยู่ ข้อนี้คือการคัดสรร ไม่ใช่การเรียนรู้
6. การใช้พลังงานทิ้งร่องรอยไว้ในสิ่งแวดล้อม และอ่านกลับได้ทีหลัง
7. เครื่องมือคือดุลยภาพระหว่างระบบที่มีปฏิสัมพันธ์กัน ในความหมายของดุลยภาพ Nash ในเกมเชิงพลวัต

เป้าหมายเชิงประยุกต์ (ผู้เขียน 2026-11-17): ถ้าสมการบอกได้ว่าอะไรทำให้ระบบคงอยู่
ให้ใช้สมการนั้นปรับปรุงการใช้ทรัพยากรของระบบจริง และทดสอบกับข้อมูลจริงทีละ topic

## 3. UET สร้างจากทฤษฎีที่มีอยู่อย่างไร

สมการไม่ได้มาจากคณิตศาสตร์ล้วน ๆ ทุกขั้นของตรรกะข้างบนยืมผลที่ตีพิมพ์แล้วมาใช้ และงานวิจัยตรวจว่ายืมมาถูกไหม
การตรวจฉบับเต็มพร้อมแหล่งและคำตัดสินทุกข้ออยู่ที่ [`core/SYNTHESIS_AUDIT.md`](core/SYNTHESIS_AUDIT.md)

| ขั้น | ผลที่ยืมมา (แหล่ง) | เงื่อนไขในต้นฉบับ | UET ใช้อย่างไร | คำตัดสิน |
|---|---|---|---|---|
| 1 | กฎข้อ 2 และสมดุล entropy ของระบบเปิด dS = dₑS + dᵢS (Prigogine) | ระบบโดดเดี่ยว / ระบบที่สัมผัสสิ่งแวดล้อม | โครงสร้างที่ต้องเผาพลังงานต้องเปิด | ใช้ถูก หลังผู้เขียนจำกัดให้เหลือ dissipative structure |
| 2 | ระบบย่อยในสิ่งแวดล้อม (Caldeira & Leggett, *Physica A* 121, 587, 1983) | สิ่งแวดล้อมใหญ่ อยู่ในสมดุลที่อุณหภูมิ T | สสารอย่างเดียวเป็นระบบเปิด รวมกับสิ่งแวดล้อมเป็นระบบปิด | ใช้ถูก (แรงเสียดทาน noise และกฎข้อ 2 เกิดขึ้นเองโดยไม่ต้องใส่) |
| 2, 6 | แรงโน้มถ่วงตอบสนองต่อสสาร G = κT (Einstein 1915) และ scalar-tensor (Damour & Esposito-Farèse, *PRL* 70, 2220, 1993) | ทฤษฎีสนามแบบอนุรักษ์ | สสารเขียนประวัติของมันลงบนความโค้งของ space | ใช้ถูก (derive แล้ว ตรวจกับดวงอาทิตย์ใน T006) |
| 6 | หลักของ Landauer (Landauer 1961) | การลบข้อมูลขณะสัมผัส bath | "ใช้พลังงาน = เขียนข้อมูล" | ต้องแก้: บิต = Σ/ln2 แยกเป็นบันทึกกับความต่างศักย์ (Esposito et al., *NJP* 12, 013013, 2010) |
| 5 | Little's law, N = λW (Little 1961) | สภาวะคงตัว | จำนวนที่เห็น = อัตราการเกิด × อายุ | ใช้ถูก (ทดสอบกับดาวและไอโซโทปแล้ว) |
| 4 | อายุ = ทุนพลังงาน ÷ อัตราเผา | อัตราเผาคงที่ | τ = F/P กับทุกระบบ | จำกัดขอบเขต: ระบบ passive ต้องใช้ τ = ∫dF/P(F) |
| 5 | R\* ต่ำสุดชนะการแย่งทรัพยากร (Tilman 1982; MacArthur 1970) | ระบบที่สร้างตัวเองเพิ่มและแย่งทรัพยากรร่วมกัน | สิ่งที่บริหารทรัพยากรดีที่สุดจะเหลืออยู่ | จำกัดขอบเขต: ใช้ได้กับระบบที่สร้างตัวเองเพิ่ม (สิ่งมีชีวิต เลเซอร์) ใช้กับดาวไม่ได้ |
| 7 | ดุลยภาพ Nash / ESS (Maynard Smith & Price 1973) | payoff ขึ้นกับว่าคนอื่นเลือกอะไร | ดุลยภาพระหว่างระบบ | จำกัดขอบเขต: ต้องมีทรัพยากรตั้งแต่สองชนิดจึงได้ดุลยภาพผสมจริง |
| 3 | ไม่มีอะไรหยุดนิ่ง (กฎข้อ 3, zero-point) | ไม่มีสถานะที่ไม่เคลื่อนไหวเลย | Λ_eff > 0 จึงไม่มีคำตอบสถิต | ใช้ถูก ในความหมายที่ผู้เขียนเลือก |

เมื่อนำชิ้นส่วนมาต่อกัน เจอข้อขัดแย้งจริงหนึ่งข้อ: ระบบที่ยึดด้วยแรงโน้มถ่วงมีความจุความร้อนเป็นลบ ระบบปิดที่มีแรงโน้มถ่วงจึงสร้างโครงสร้างเพิ่มได้
ขณะที่ entropy รวมยังเพิ่มขึ้น (Lynden-Bell & Wood 1968) ผู้เขียนจึงรับถ้อยคำที่แคบลงในขั้น 1
ยังมีอีกจุดเชื่อมที่ยังเปิดอยู่: Caldeira–Leggett ต้องมีสิ่งแวดล้อมที่มีอุณหภูมิ แต่ทฤษฎีสัมพัทธภาพทั่วไปไม่ให้อุณหภูมิกับ space
ยกเว้นที่ขอบฟ้า การอ่านตอนนี้คือ space เก็บบันทึก ส่วนรังสีและสสารเป็นตัวรับความร้อน

### ทฤษฎีที่มีอยู่แล้วที่ใกล้ที่สุดของแต่ละชั้น

แต่ละชั้นลดรูปเป็นทฤษฎีที่มีอยู่แล้ว (ผล [`R_B4_DISTINCTNESS_AUDIT`](docs/standard/results/R_B4_DISTINCTNESS_AUDIT.json))

| ชั้น | ทฤษฎีที่ใกล้ที่สุด |
|---|---|
| 1. การแลกเปลี่ยน | scalar-tensor ของ Damour–Esposito-Farèse กับ Yukawa portal |
| 2. ระบบเปิด | กลศาสตร์ระบบเปิดของ Caldeira–Leggett และ entropy production ของ Prigogine |
| 3. การคัดสรร | การแข่งทรัพยากรของ Tilman และสมการ rate ของเลเซอร์หลายโหมด (ตรงทุกเทอม) |

ที่ระดับ action **ยังไม่มีความต่าง**จากคลาสทฤษฎีที่มีอยู่
**UET ยังไม่มีการทำนายที่เป็นของตัวเอง**: ผลข้ามชั้นเพียงตัวเดียวที่ไม่มีคู่ในทฤษฎีมาตรฐานยังขึ้นกับ parameter อิสระสามตัว
สิ่งที่ UET เพิ่มได้คือแผนที่ที่ทดสอบแล้วว่ากฎชุดเดียวใช้ได้ข้ามสาขาตรงไหน และใช้ไม่ได้ตรงไหน

## 6. วิธีทำวิจัย

กติกาหลักคือ [`docs/STANDARD.md`](docs/STANDARD.md) (Research Standard v2) สรุปสั้น ๆ:

- ทุกข้ออ้างต้องระบุทฤษฎีที่มีอยู่แล้วที่ใกล้ที่สุด และบอกว่าต่างจากมันตรงไหน
- Test Card กำหนดเกณฑ์ตัวเลขผ่าน/ไม่ผ่าน และผู้เขียนอนุมัติก่อนเทียบข้อมูลภายนอก
- ข้อมูลที่ใช้ fit จะไม่ถูกใช้ทดสอบซ้ำ ข้อมูลดิบภายนอกล็อก hash ไว้ใน [`docs/standard/data_manifest.json`](docs/standard/data_manifest.json)
- AI ช่วย derive เขียนโค้ด และร่างเอกสาร แต่อนุมัติการ์ดหรือเลื่อนระดับข้ออ้างเองไม่ได้
- การตีความของ AI ติดป้ายไว้ และไม่ใช้แทนเจตนาของผู้เขียน

## 8. รันตรวจซ้ำเอง

```bash
git clone https://github.com/unityequilibrium/UnityEquilibriumTheory.git
cd UnityEquilibriumTheory
python -m venv .venv
.venv/Scripts/pip install -r .github/requirements-research.txt   # Windows; เครื่องอื่นใช้ .venv/bin/pip
```

```bash
python -m pytest -q core/05_tests/physics
```

```bash
python docs/scripts/standard/check_schema.py
```

```bash
python docs/scripts/standard/check_preregistration.py
```

Test Card แต่ละใบระบุสคริปต์ที่สร้างผล รันสคริปต์นั้นซ้ำจะได้ตัวเลขเดียวกับที่บันทึกไว้

## สิ่งที่เปลี่ยนใน v0.9.1

- หน้านี้เปิดด้วยสมการหลัก: แนวคิด Ω = C·I เดิม และสามชั้นที่ทำให้มันคำนวณได้จริง
- อธิบาย UET ตามที่ผู้เขียนนิยาม: ขั้นตอนคำนวณสำหรับระบบ สร้างจากการสังเคราะห์ทฤษฎีที่ตีพิมพ์แล้ว
- หัวข้อ 3 แทนแผนภาพ "Tree of Physics" เดิม ด้วยผลที่ยืมมาแต่ละข้อ แหล่ง และคำตัดสินว่าใช้ถูกไหม
- ตารางหลักฐานดึงจากทะเบียนข้ออ้าง รวมผลที่ไม่ชี้ขาดด้วย
- ตารางหัวข้อวิจัยแสดงครบ 40 topic พร้อมคำถามที่แต่ละ topic ศึกษา แทนเครื่องหมาย "Solved"
- dashboard ของ v0.9.0 ("38 Solutions", Millennium Problems, สรุปผลทดสอบ v0.9.0 และตารางคำถามสำหรับ SEO)
  เก็บไว้ที่ [`docs/history/LEGACY_CLAIMS.md`](docs/history/LEGACY_CLAIMS.md) ติดป้าย `LEGACY_UNREVIEWED` ไม่มีข้อไหนมีผลปัจจุบันรองรับ
- เอาส่วน Uet-Cash ออก เพราะเป็นอีกโปรเจกต์หนึ่งแล้ว
- ลิงก์ชี้ไปโฟลเดอร์ `core/` และ `topics/` ปัจจุบัน
