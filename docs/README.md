# Unity Equilibrium Theory

UET is a research program that joins established results from thermodynamics, gravity, open-system physics and
ecology into one calculation procedure for how systems use resources. It is a synthesis, not a claim of new physics.

**Where it stands:** every layer of UET reduces to a theory that already exists, and no claim yet gives a number that
differs from standard physics (claim `C_B4_DISTINCTNESS_AUDIT`). Results that agree with data agree because the
established physics they reuse agrees. Failed tests are kept as results.
