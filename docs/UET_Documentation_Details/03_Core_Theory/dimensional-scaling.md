# Dimensional Scaling (การปรับสเกลของมิติ)

การทำให้ตัวแปรไร้หน่วยช่วยระบุว่าพารามิเตอร์ใดควบคุมแบบจำลอง แต่ **ไม่ใช่หลักฐานของ scale invariance** และไม่แสดงว่าทฤษฎีเดียวใช้ได้ตั้งแต่ควอนตัมถึงจักรวาล UET ยังไม่ได้แสดงการลดรูปข้ามสเกลที่ยืนยันข้ออ้างนั้น

## สิ่งที่เป็นข้อเสนอ

[แบบจำลองผู้สมัคร 7 เทอมในประวัติการพัฒนา](the-master-equation.md) เคยเสนอให้ใช้รูป functional ที่คล้ายกันในหลายบริบท โดยเปลี่ยนพารามิเตอร์ เช่น $\kappa$, $\beta$ และ $\gamma_J$ นี่เป็นแนวทางสร้างแบบจำลอง ไม่ใช่ scaling law ที่ derive หรือวัดแล้ว ตัวเลขพารามิเตอร์เชิงตัวอย่างในฉบับเก่าไม่ใช่ค่ามาตรฐาน และไม่ควรนำไปใช้เป็น input ทางกายภาพโดยไม่มี provenance

เทอม coherence $\lambda \sum (C_i - C_j)^2$ เป็น penalty สำหรับความต่างระหว่างส่วนที่แบบจำลองประกาศไว้ ไม่ได้พิสูจน์ว่ามีแรงหรือกฎ coherence สากล และไม่รับประกันเสถียรภาพโดยลำพัง

## สิ่งที่ต้องตรวจก่อนอ้างว่าข้ามสเกลได้

1. กำหนด state, observable, หน่วย และสเกลอ้างอิงของแต่ละ lane โดยไม่สมมติว่า $C$ หมายถึงปริมาณเดียวกัน
2. แสดง mapping หรือการลดรูปพร้อมเงื่อนไขขอบเขต ที่มาของสัมประสิทธิ์ และเกณฑ์ residual หรือ convergence
3. ตรวจ observable และความไม่แน่นอนกับข้อมูลหรือ benchmark ที่เหมาะสม ก่อนอ้างความสอดคล้องทางกายภาพ
