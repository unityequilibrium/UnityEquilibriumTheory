# Axioms and Principles

ข้อเสนอทั้งสิบด้านล่างเป็นแนวคิดตั้งต้นในประวัติ UET ไม่ใช่สัจพจน์ทางฟิสิกส์ที่พิสูจน์แล้ว และการยอมรับสมมติฐานไม่ใช่การยืนยันผลทางกายภาพ ดู [สัญญา axioms ปัจจุบัน](../../core/01_contracts/UET_MAIN_THEORY_AXIOMS_SPEC.md) และ [สถานะ foundation](../../core/01_contracts/UET_FOUNDATION_STATUS_AGGREGATE.md)

## หลักฟิสิกส์ที่ใช้อ้างอิง

- **Landauer:** ใช้เป็นขอบเขตล่างของพลังงานสำหรับการลบบิตที่ย้อนกลับเชิงตรรกะไม่ได้ ภายใต้เงื่อนไขของขอบเขตนั้น ไม่ใช่ข้ออ้างว่าข้อมูลมีน้ำหนักหรือว่าทุกการประมวลผลต้องจ่ายต้นทุนเท่ากัน ค่า SI นี้แยกจาก normalized beta
- **สมดุลของระบบเปิด:** ระบุขอบเขตระบบและสิ่งที่ไหลผ่านก่อนใช้สมการดุล การศึกษา effective subsystem แบบเปิดไม่ได้แปลว่าเอกภพทั้งหมดเปิด

## แนวคิดในประวัติ UET

| แนวคิด | ขอบเขตที่ใช้ได้ |
| --- | --- |
| 1. สสารและพลังงานในมุมการคำนวณ | กรอบตีความ ไม่ใช่การพิสูจน์ว่าสสารคือการคำนวณ |
| 2. ต้นทุนของข้อมูล | ใช้ Landauer ในเงื่อนไขที่ประกาศไว้เท่านั้น ไม่เท่ากับ coupling ของแบบจำลอง |
| 3. ต้นทุนการเปลี่ยนสถานะ | Gradient penalty เป็นเทอมของ functional; ยังไม่ใช่พลังงานสูญเสียหรือความเฉื่อยโดยอัตโนมัติ |
| 4. การแลกเปลี่ยนกับสิ่งแวดล้อม | สมมติฐานของ subsystem ที่ระบุ flux และขอบเขตได้ ไม่ใช่ข้อสรุปว่าทุกระบบกึ่งเปิด |
| 5. การคงอยู่ | ข้อเสนอให้ทดสอบ persistence ด้วย observable ที่ระบุได้ ไม่ใช่เจตจำนงหรือแรงพื้นฐาน |
| 6. มูลค่า | สมมติฐานเชิงแบบจำลอง ไม่ใช่ปริมาณกายภาพหรือสมการแปลงพลังงานเป็นมูลค่า |
| 7. สมดุลแบบเกม | ใช้ได้เมื่อประกาศผู้เล่น กลยุทธ์ และ payoff; ไม่ถือว่าทุกสมดุลเป็น Nash equilibrium |
| 8. ความสอดคล้องระหว่างชั้น | Coherence penalty เป็นตัวเลือกในแบบจำลอง ไม่ใช่กฎข้ามสเกล |
| 9. การหาค่าที่เหมาะสม | Functional descent ต้องตรวจใน operator ที่ประกาศไว้ ไม่ได้แปลว่าเอกภพกำลังลด functional นี้ |
| 10. กรอบร่วมระหว่างสาขา | เป็นเป้าหมายวิจัย แต่ยังไม่มีหลักฐานว่ากฎชุดเดียวครอบคลุมฟิสิกส์ ชีววิทยา และเศรษฐศาสตร์ |
