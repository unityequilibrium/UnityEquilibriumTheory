## 2. สิ่งที่ผิดก่อนหน้านี้ (ตรวจเมื่อ 8 พ.ย.)

- **ชื่อสถานะเฟ้อ:**
  - ค่าสถานะต่างกัน 639 แบบ ในจำนวนนี้ 312 แบบขึ้นต้นด้วย `PASS_`
  - **ผลลบถูกตั้งชื่อเป็น PASS** เช่น `PASS_SCOPED_..._NO_GO`
- **AI ตั้งเกณฑ์ให้ตัวเองแล้วตรวจตัวเอง:** "13/13 acceptance" ของ Topic 13 นับเกณฑ์ "ไม่ได้แตะข้อมูล holdout" เป็นข้อที่ผ่าน และหั่น scope จนได้สถานะ `CLOSED_FOR_CORE` ทั้งที่ gate รวมยังเป็น BLOCKED
- **gate เปราะ:**

  - ตัวคุมสถานะไม่ได้ regenerate ตั้งแต่ ส.ค.
- **ไม่เคยเทียบกับข้อมูลภายนอกเลย** ทั้งที่เป็นสิ่งเดียวที่ตัดสินได้ว่าทฤษฎีถูกหรือผิด

### 2.2 สมการแกน
พบ 3 ชุดที่ถูกเรียกว่า "สมการหลัก":
1. **Master Equation 7 เทอม** ([`the-master-equation.md`](../UET_Documentation_Details/03_Core_Theory/the-master-equation.md), `uet_master_equation.py`) ถูกลดสถานะเป็น legacy comparator ไปแล้ว แต่ README หลักยังอ้างว่าเป็นสมการหลัก
   - `natural_will_term` = `W_N Σ|∇C|` เป็นแค่ผลรวมความชัน ไม่มีทรัพยากร อายุ หรือการคัดสรรอยู่ในนั้นเลย
   - `game_theory_potential` = `β_U C²` เป็น potential คงที่ ไม่ใช่เกม
2. **Matter-space (C, Φ, Π)** เป็นแบบจำลอง 1 มิติในหน่วย normalized
3. **Covariant parent action** เป็นตัวที่ใช้คุมจริง แต่ Codex สร้างขึ้นเอง และเป็น scalar-tensor แบบ DEF บวก O(2) ซึ่งเป็นคลาสทฤษฎีที่มีอยู่แล้ว
   - "exact GR null" เป็น tautology เพราะโค้ดเขียนไว้ว่า `if ε == 0: return GR`
   - ε ซ้ำซ้อน (ดูดซับได้ด้วยการ rescale field) และ ε = 0 เป็นจุดเสื่อม ไม่ใช่ GR limit

### 2.3 การตีความเจตนาของผู้เขียน (ผิด 3 จุดใหญ่)
| คำของผู้เขียน | AI ตีความเป็น | ความหมายจริง |
|---|---|---|
| จักรวาลเปิด | จักรวาลแลกเปลี่ยนกับ**ภายนอก** | สสารมีปฏิสัมพันธ์กับ**โครงสร้างของจักรวาล** (ระบบย่อยเปิด) |
| การเรียนรู้ | การเรียนรู้หรือปรับตัวแบบสมอง | การบริหารทรัพยากรที่ถูก**คัดสรร**: สิ่งที่บริหารไม่ดีหมดทรัพยากรแล้วหายไป |
| Natural Will / การคงอยู่ | **แรง**หรือเทอมในสมการของระบบเดียว | ชั้น**การคัดสรรของกลุ่มระบบ** ซึ่งใส่ลงในสมการของระบบเดียวไม่ได้ |
