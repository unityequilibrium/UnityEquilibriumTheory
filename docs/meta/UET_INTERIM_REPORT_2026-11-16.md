## 3. ผลเก่ากับมาตรฐานใหม่: ผิด, ไม่ใช่หลักฐาน, หรือยังใช้ได้

ผลเก่าทั้งหมดยังเก็บไว้ไม่แก้ ป้ายเป็น `LEGACY_UNREVIEWED` ตารางนี้แยกตามสิ่งที่รู้ตอนนี้

### 3.1 ผิด มีหลักฐาน

| เรื่อง | หลักฐาน |
|---|---|
| lane He-4 ของ topic 13 ที่ให้ Φ = superfluid fraction และ χ = อะตอม He-4 | T015 FAILED: ความเร็วเสียงผิด 3.6 เท่า และ He II หนาแน่นเกินกว่าภาค O(2) ของ action จะอธิบายได้ (n a³ = 2.5×10⁴) ผู้เขียนตัดสินให้เป็น phenomenological closure นอก action (16 พ.ย.) |
| ความจำเป็นต้องเลือก E_ref หรือ e0 เพื่อแปลงเป็น SI | SI-1: เป็นผลของ Φ แบบ normalized เท่านั้น action มีหน่วยของตัวเองอยู่แล้ว |
| "exact GR null ที่ ε = 0" ในโค้ดเดิม | เป็น tautology: ε = 0 คือจุดเสื่อม ไม่ใช่ limit ไปหา GR (Theory Card §5) |
| ผลลบที่ตั้งชื่อเป็น PASS และการหั่น scope จนได้ `CLOSED_FOR_CORE` | รายงาน 9 พ.ย. §2 |

### 3.2 ไม่ผิด แต่ใช้เป็นหลักฐานของ UET ไม่ได้

| เรื่อง | เหตุผล |
|---|---|
| ผลของเกือบทุกท็อปิก | คำนวณด้วย engine เฉพาะท็อปิก (`Engine_*.py` ราว 70 ไฟล์) ท็อปิก import core 166 ครั้ง แต่เพื่อหา path เท่านั้น ไม่มีท็อปิกไหนเรียก parent action |
| `get_params(topic)` ใน `core/__init__.py` | ให้ κ, β แยกตามท็อปิก ขัดกับ "กฎเดียวทุกสเกล" (ทาง ก ที่ผู้เขียนเลือก) |
| ท็อปิกที่มีค่า fit หรือค่ายึดกับ benchmark | เช่น Hubble ที่เลือก √α_em หลัง β ที่ derive ตก (retrospective R09), ท็อปิกนิวเคลียร์ที่ใช้ค่าสัมประสิทธิ์ SEMF |
| ผลของ topic 13 ทั้งหมด | ใช้เป็นแบบจำลอง phenomenological ได้ แต่ไม่ใช่หลักฐานของ action |
| Muon g-2 (0.8) | ไม่ได้ผิด แต่ไม่มี anomaly ให้อธิบายแล้ว (SM ปี 2025 ต่างจากการทดลอง 0.6σ) |

### 3.3 ยังใช้ได้และผ่านมาตรฐานใหม่

- Test Card T001–T014 ในข้อ 2.1 (ยกเว้น T015 ที่ตก)
- กฎชั้น 2–3 (F, P, τ = ∫dF/P, N = bτ) ยืนยันแล้วกับดาว ระบบนิเวศ laser และ decay chain นี่คือส่วนที่เป็น "กฎเดียวข้ามสเกล" ที่ผู้เขียนตั้งใจได้ชัดที่สุด
- การนำร่อง engine (16 พ.ย.) คำนวณ T002, T014, T008 ใหม่ผ่าน engine กลาง ได้ตัวเลขตรงกับที่บันทึกไว้ทุกตัว

## 4. สิ่งที่เรียนรู้

1. **ทุกชั้นลดรูปเป็นทฤษฎีที่รู้จักแล้ว** (B4): ชั้น 1 = scalar-tensor แบบ DEF + Yukawa portal, ชั้น 2 = open system แบบ Caldeira–Leggett, ชั้น 3 = Little's law และการแข่งขันแย่งทรัพยากร
   นี่ไม่ใช่ข้อเสียของทฤษฎีสังเคราะห์ เพราะเกณฑ์คือใช้แต่ละหลักการถูกต้องและประกอบกันได้ ซึ่งผ่าน
2. **ผลที่ข้ามชั้นเพียงอย่างเดียวที่พบ (portal drag) กลายเป็นฟิสิกส์แรงที่ห้าธรรมดา** (B6): Γ ไม่ใช่ค่าอิสระ และเล็กกว่าขอบเขตการรอดชีวิตของระบบสุริยะ 10³⁰ เท่า
3. **ψ ถูกจำกัดแน่นจนผลในห้องแล็บวัดไม่ได้** (T005, SI-1): ในของไหลได้แค่ 10⁻¹⁸
4. **ตรวจท็อปิกทั้ง 27 ตัวด้วย 3 เกณฑ์ ไม่มีตัวไหนผ่านครบ** ([`TOPIC_DISTINCTNESS_SCREEN_2026-11-16.md`](TOPIC_DISTINCTNESS_SCREEN_2026-11-16.md))
5. **action ตอนนี้ไม่มี fermion และ gauge field** ท็อปิกนิวเคลียร์ อะตอม และอนุภาค (0.5–0.8, 0.16, 0.17, 0.20, 0.21) จึงเข้าไม่ถึงสมการแกนเลย จนกว่าผู้เขียนจะตัดสินใจขยาย action
6. **ความต่างจากฟิสิกส์มาตรฐาน ถ้ามี ต้องมาจากชั้น 2–3 ของเจตนาผู้เขียน** (สสารแลกเปลี่ยนกับโครงสร้างของ space, การเขียนข้อมูล, การบริหารทรัพยากร) ซึ่งยังไม่อยู่ใน action
7. **ปัญหาเดิมของ topic 13 เป็นปัญหาโครงสร้าง ไม่ใช่ปัญหาข้อมูล** การไล่หา data package ของ graphite ต่อจะไม่ช่วย (หยุดแล้วตามที่ผู้เขียนตัดสิน)

## 6. แผนต่อไป (AI เสนอ ให้ผู้เขียนเลือก)

1. **ย้ายท็อปิกเข้า engine กลาง** ([`core/engine/README.md`](../../core/engine/README.md)) ทีละตัว เริ่มจากท็อปิกที่มีโฟลเดอร์จริงและ action เข้าถึงได้ (0.19 GR ชั้น 1 หรือ 0.22 biophysics ชั้น 2–3) ผลที่เปลี่ยนหรือตกต้องบันทึกตรง ๆ
2. **หาข้อทำนายใหม่** อย่างมากสอง candidate ตาม stop rule
   - A: ψ เป็น dark matter (ใช้ action เดิม แต่มีแนวโน้มออกมาเป็น fuzzy dark matter ที่รู้จักแล้ว)
   - C: สุญญากาศจากการสะสมการเขียนข้อมูล (ไอเดียผู้เขียน 9 พ.ย. เป็น candidate เดียวที่ ΛCDM ไม่มี แต่ต้องเพิ่มเทอมใหม่)
   - ทาง (ข): เขียนชั้น 2 ลงใน action ให้ ψ ต่อกับ entropy ของสสาร
3. ถ้าทั้งหมดไม่ให้ตัวเลขที่ฟิสิกส์มาตรฐานไม่มี ให้บันทึกตามนั้น และนำเสนอ UET เป็นกรอบรวม (unifying framework) ไม่ใช่ฟิสิกส์พื้นฐานใหม่
