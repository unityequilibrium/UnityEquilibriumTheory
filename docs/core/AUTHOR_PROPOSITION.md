## 1. ตรรกะหลัก (สรุปจากคำของผู้เขียน)

1. **[ผู้เขียน]** ฐานคือกฎเทอร์โมไดนามิก ระบบปิดมีความไร้ระเบียบเพิ่มขึ้นจนไม่เหลือโครงสร้าง สิ่งที่ยังมีโครงสร้างอยู่จึงต้อง**เปิด**
2. **[ผู้เขียน]** "เปิด" **ไม่ได้**หมายถึงจักรวาลแลกเปลี่ยนกับภายนอก ความหมายคือ เมื่อนับสสารเป็นระบบหนึ่ง การเปลี่ยนแปลงของสสารคือปฏิสัมพันธ์ระหว่างสสารกับ**โครงสร้างของจักรวาล**
   - **[ผู้เขียน 2026-11-10]** ในสมการ χ คือสสารธรรมดา ผลคือ portal ให้แรง Yukawa ที่ทดสอบได้ (ดู [`FIDELITY_MATRIX.md`](FIDELITY_MATRIX.md) B1b)
3. **[ผู้เขียน]** ไม่มีอะไรหยุดนิ่งได้ (เช่น แรงโน้มถ่วงดึงทุกอย่างตลอดเวลา) ทุกสิ่งจึงมีพฤติกรรมอยู่ตลอด
   - **[ผู้เขียน 2026-11-10]** ในสมการ ให้หมายถึง Λ_eff > 0: vacuum ขยายตัวเสมอจึงไม่มีคำตอบสถิต (ดู [`FIDELITY_MATRIX.md`](FIDELITY_MATRIX.md) ข้อ 3)
4. **[ผู้เขียน]** พฤติกรรม = การ**ใช้**พลังงาน ซึ่งไม่ได้หมายถึงสูญเสียพลังงาน ระบบที่มีพฤติกรรมมากใช้ทรัพยากรมากและอยู่ได้สั้น ระบบที่บริหารทรัพยากรดีอยู่ได้นาน
5. **[ผู้เขียน]** สิ่งที่บริหารทรัพยากรไม่ดีจะหมดและหายไป จึงไม่ผ่านการคัดสรรตามธรรมชาติ และเราจะไม่เห็นมันในจักรวาล ข้อนี้**ไม่ใช่การเรียนรู้** และไม่มีเจตนาเข้ามาเกี่ยว
6. **[ผู้เขียน — เป้าหมายเชิงประยุกต์]** ในอุดมคติ ถ้าสมการทำให้เข้าใจได้ว่าอะไรทำให้ระบบอยู่รอด เราควรนำความเข้าใจนั้นไปใช้บริหารทรัพยากรให้ดีขึ้น
   ข้อนี้ไม่ได้อ้างว่า "รอด = บริหารเก่ง" แต่เป็นเป้าหมายของการนำทฤษฎีไปใช้
7. **[ผู้เขียน]** การใช้พลังงานทำให้เกิดการ **encode** ลงบน space ร่องรอยนี้ไม่ใช่ต้นทุน แต่เป็นข้อมูลของสิ่งที่เกิดขึ้นไปแล้ว และสังเกตได้ทีหลัง (observable) ซึ่งเชื่อมกับทฤษฎีของไอน์สไตน์
8. **[ผู้เขียน]** **Landauer กลับด้าน:** ถ้ามองจักรวาลเป็นข้อมูล การลบข้อมูลต้องใช้พลังงาน ดังนั้นการใช้พลังงานก็คือการเขียนข้อมูลลงบนจักรวาล
9. **[ผู้เขียน]** จักรวาลไม่ว่างเพราะร่องรอยที่ถูก encode สะสมมา
10. **[ผู้เขียน]** เครื่องมือทางคณิตศาสตร์คือดุลยภาพของปฏิสัมพันธ์แบบ Nash ในรูป**เกมเชิงพลวัต**

## 2. โครงสมการ 3 ชั้น [ตีความโดย AI จากข้อ 1–10]

### ชั้น 1 — สสารแลกเปลี่ยนกับโครงสร้างของ space (ข้อ 2, 7)

```
[มาตรฐาน]   dE_matter/dt = − dE_structure/dt        สสารอย่างเดียวไม่อนุรักษ์ รวมกับโครงสร้างแล้วอนุรักษ์ได้
[มาตรฐาน]   G_μν = κ T_μν                           สสาร "เขียน" ตัวเองลงบนความโค้งของ space
```

ใน repo ชั้นนี้คือ parent action ใน [`THEORY_CARD.md`](THEORY_CARD.md) ซึ่งมีบัญชีแลกเปลี่ยน `Q_m + Q_response = 0` ระหว่างสสาร χ กับสนาม Φ
สถานะคือ L1 (สมการ derive จาก action ได้) และ L2 แบบ constraint (T001 binary pulsar)

### ชั้น 2 — เทอร์โมของระบบเปิดและการเขียนข้อมูล (ข้อ 1, 3, 4, 7, 8)

```
[มาตรฐาน]   dS_sys = dₑS + dᵢS ,   dᵢS ≥ 0               (Prigogine; dₑS < 0 ได้เมื่อระบบเปิด)
[มาตรฐาน]   P = T · Ṡ_prod                               กำลังที่เผา = "พฤติกรรม" ที่ใช้ทรัพยากร
[มาตรฐาน]   ΔS_env = Q/T ,  S = k ln2 · (bits)
[อนุมาน]    อัตราเขียนข้อมูลลงสิ่งแวดล้อม = P / (k T ln2)    ← Landauer กลับด้าน (ข้อ 8)
[มาตรฐาน]   ข้อมูลที่อ่านกลับได้เกี่ยวกับอดีต ≤ บิตที่ถูกเขียนทั้งหมด
```

**การแปลคำ [ตีความโดย AI]:**
- **ทรัพยากร** = พลังงานอิสระ F (หรือ negentropy) ไม่ใช่พลังงานรวม เพราะพลังงานรวมอนุรักษ์ตามกฎข้อ 1 ส่วนที่ "ใช้แล้วหมด" คือ F
  - การเคลื่อนที่แบบอนุรักษ์ (เช่น วงโคจร) ไม่ได้เผา F
  - การรักษาโครงสร้างให้ห่างจากสมดุลต้องเผา F ตลอดเวลา
- **ข้อ 3 "ไม่มีอะไรหยุดนิ่ง"** ตรงกับกฎข้อ 3 (ลดอุณหภูมิถึงศูนย์สมบูรณ์ไม่ได้) และพลังงาน zero-point ในควอนตัม ผู้เขียนเคยผูกกฎข้อ 3 ไว้กับ "การเปิด" แต่การผูกกับข้อ 3 นี้ตรงกับตัวกฎมากกว่า
- **กฎข้อ 0** นิยามอุณหภูมิผ่านสมดุลแบบถ่ายทอด ส่วนระบบเปิดที่มีพลังงานไหลผ่านมักไปอยู่ที่ steady state ไม่ใช่สมดุล
- **ร่องรอยที่สังเกตได้ทีหลัง** คือส่วนย่อยของสิ่งที่ถูก encode ที่ยังเป็นระเบียบพออ่านกลับได้ ส่วนที่เหลือกลายเป็นความร้อน
  - ร่องรอยเดินทางได้ไม่เร็วกว่าแสง จึงสังเกตได้ทีหลังเสมอ ภายใน light cone

ใน repo ชั้นนี้**ยังไม่มีสมการ** คือ blocker `full_sk_kms_derivation` ใน [`uet_main_theory_closure_gate.json`](07_artifacts/gates/uet_main_theory_closure_gate.json)

### ชั้น 3 — การคัดสรรด้วยการบริหารทรัพยากร (ข้อ 4, 5, 6, 10)

```
[อนุมาน]        τ = F_store / P                          อายุ = ทุนพลังงานอิสระ ÷ อัตราเผา
[มาตรฐาน]       N_observed ∝ (อัตราการเกิด) × τ           ตัวอย่าง: สัดส่วนดาวใน main sequence
[สมมติฐาน UET]  dxᵢ/dt = xᵢ (fᵢ − f̄)                     replicator dynamics; fitness fᵢ วัดจากการคงอยู่
[สมมติฐาน UET]  เกม "เผาเร็ว vs เผาช้า"                   เร็ว = ชนะการแข่งขันระยะสั้น (Lotka), ช้า = อยู่นาน → จุดสมดุล = ESS
```

- **เงื่อนไขกันวนเหตุผล [มาตรฐานการพิสูจน์]:** ถ้าจะใช้ชั้นนี้อธิบายธรรมชาติ ต้องคำนวณ τ จาก F และ P **แยกต่างหาก**ก่อน แล้วค่อยเทียบกับจำนวนที่สังเกตได้
- **การประยุกต์ (ข้อ 6):** เมื่อได้ τ(F, P, กลยุทธ์) ที่ผ่านการทดสอบแล้ว ก็ใช้หากลยุทธ์ที่ยืดอายุระบบได้ เช่น ในการบริหารทรัพยากร เป็นการใช้ทฤษฎี ไม่ใช่หลักฐานของทฤษฎี
- **งานที่ใกล้เคียงซึ่งต้องเทียบ:** Schrödinger, *What is Life?* (1944); Lotka maximum power (1922); England, dissipative adaptation (2013); r/K selection; Maynard Smith และ Price, ESS (1973)

ใน repo: [`03_lanes/persistence/uet_persistence_selection.py`](03_lanes/persistence/uet_persistence_selection.py) (claim `C_L3_SELECTION_FORMAL`, **L1**, 2026-11-09) ระบบหายไปเมื่อพลังงานอิสระหมด แล้วได้ผลสามข้อโดยไม่ต้องตั้ง payoff ด้วยมือ: Little's law `N* = b·τ`, replicator dynamics ที่ออกมาเป็น identity และผู้ชนะคือระบบที่มี `R* = P/(aF)` ต่ำสุด ซึ่งเป็น ESS ของเกม "เผาเร็ว vs เผาช้า"
ยังไม่ได้ derive จาก parent action
**T002 (L2, 2026-11-09):** เทียบกับกระจุกดาวทรงกลม 39 กระจุก ทำนายสัดส่วนดาว HB/RGB ได้ 1.467 ± 0.023 เทียบกับที่นับได้จริง 1.39 ± 0.03 ห่าง z = 2.05 จึงได้ผล **INCONCLUSIVE** (ไม่ใช่การตก) ในภาษาชั้น 3 ความตึงนี้หมายถึงช่องเผาพลังงานที่ยังไม่อยู่ในแบบจำลอง ซึ่งทำให้ τ_HB สั้นลง การทดสอบนี้แยก UET ออกจาก fuel-consumption reasoning มาตรฐานไม่ได้

## 3. ผลอนุมานที่ทดสอบได้ [อนุมาน]

ถ้าระบบเผาพลังงานอิสระทั้งหมดที่อุณหภูมิคงที่ T:

```
บิตที่ระบบเขียนลงจักรวาลตลอดชีวิต = ∫ P/(kT ln2) dt = F_store / (kT ln2)
```

จำนวนข้อมูลทั้งหมดที่ระบบทิ้งไว้ให้จักรวาล**ขึ้นกับทุนพลังงานอิสระอย่างเดียว ไม่ขึ้นกับว่าเผาเร็วหรือช้า** ความเร็วในการเผากำหนดแค่อายุ τ
- ตรวจได้กับ entropy ที่ดาวฤกษ์แผ่ออกมาตลอดอายุ
- รังสี blackbody มี entropy `(4/3)E/T` สัมประสิทธิ์จึงเปลี่ยน แต่รูปแบบความสัมพันธ์ยังเหมือนเดิม

## 5. สิ่งที่การ์ดนี้แก้จากการตีความเดิม

- **"จักรวาลเปิด"** ไม่ได้หมายถึงแลกเปลี่ยนกับภายนอก การตีความเดิมใน [`docs/meta/UET_THEORY_ARGUMENT.md`](../meta/UET_THEORY_ARGUMENT.md) §3.4 และ cosmology spec จึงผิด
- **"การเรียนรู้"** ไม่ใช่การเรียนรู้หรือปรับตัวแบบสมอง แต่คือการคัดสรรของระบบที่บริหารทรัพยากรได้
- **"Natural Will / การคงอยู่"** ไม่ใช่แรงหรือเทอมในสมการของระบบเดียว แต่เป็นชั้นการคัดสรรของกลุ่มระบบ
  นี่คือเหตุที่เทอม `W_N |∇Ω|` ใน Master Equation 7 เทอมนำไปทำต่อไม่ได้
- ตัวอย่างที่ AI เลือกเอง เช่น โซ่ 4 อะตอม, BaTiO3, He-4 ใช้ทดสอบกลไกย่อยได้ แต่ไม่ใช่ข้อกำหนดของทฤษฎี
