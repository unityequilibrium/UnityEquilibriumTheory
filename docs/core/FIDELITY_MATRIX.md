## B1b: χ = สสารธรรมดา (ผู้เขียนตัดสิน 2026-11-10)

เมื่อ χ คือสสารธรรมดา portal ½g_cψ|χ̃|² จะต่อ ψ เข้ากับมวลโดยตรง
`03_lanes/scalar_tensor/uet_portal_fifth_force.py`, `test_portal_fifth_force.py` (5 test)

- **สสารที่เคลื่อนช้า:** X = |χ̃|² = ρ/m_χ² เป็น known limit ที่ลู่เข้าแบบอันดับ 2 ผ่าน stress tensor ของโค้ด
- **สมการ ψ แบบสถิต:** ∇²ψ − m_ψ²ψ = −(g_c/2m_χ²)ρ แก้เชิงตัวเลขรอบทรงกลมแล้วลู่เข้าหาคำตอบเชิงวิเคราะห์ (อันดับ 2)
- **ผล:** ได้แรง Yukawa V = −GMm/r · [1 + α e^(−r/λ)] โดย **α = g_c²/(2κm_χ⁴)** และ λ = 1/m_ψ
  - แรงนี้แปรตามมวล จึงไม่ขึ้นกับชนิดสาร การทดสอบ equivalence principle (Eöt-Wash แบบ composition) จึงไม่เห็นแรงนี้
  - การทดสอบที่**เห็นแรงนี้**: inverse-square law (Eöt-Wash ระยะ μm–mm), Lunar laser ranging และวงโคจรดาวเคราะห์
- **สเกล:** สำหรับสสารนิวคลีออน α = 1 ต้องใช้แค่ g_c ≈ 5×10⁻¹⁰ eV
  ข้อมูลจึงบีบ g_c ได้แรงมาก เว้นแต่ ψ จะหนักพอให้ λ สั้นกว่าระยะที่วัดได้

**ผลต่อข้อสรุปเดิม**

| ข้อเดิม | ผล |
|---|---|
| C_VACUUM_SHIFT_ROUTE ทาง χ condense (m_χ² < 0) | **ถูกตัดทิ้ง** เพราะสสารธรรมดามี m_χ² > 0 เหลือแค่ทาง metastable |
| W5 / T001 ที่ใช้ α₀ = 0 | ใช้ได้เฉพาะเมื่อ portal α ≪ 1 ถ้า g_c ไม่เล็ก ดาวนิวตรอนจะมี scalar charge จาก portal เพิ่ม ทำให้ binary pulsar เปลี่ยน |

**ผลต่อคำตัดสิน**
- **ข้อ 1** `PARTIAL` → `MATCH` (ระดับโมเดล): "นับรวมเป็นระบบปิด มองสสารอย่างเดียวเป็นระบบเปิด" ได้ derive เป็นตัวเลขแล้ว ข้อจำกัดคือสิ่งแวดล้อมยังเป็น oscillator ทั่วไป ยังไม่ได้ระบุว่าเป็นสนามไหนใน parent action
- **ข้อ 8** `ASSUMED` → `PARTIAL`: บิตที่เขียน = entropy ที่ถูกผลิตจริงจาก dynamics ปิด ไม่ใช่นิยามลอย ๆ ที่ยังขาดคือ bound ของข้อมูลที่อ่านกลับได้
- **ข้อ 4** `ASSUMED` → `PARTIAL` และ**เจอข้อขัดแย้งกับชั้น 3**:
  - เมื่อแรงเสียดทานเป็นแบบ linear พลังงานอิสระจะลดแบบ exponential (F ∝ e^(−γt) อัตรา 0.2018 เทียบ γ = 0.2) แปลว่า **P ∝ F ไม่คงที่**
  - ชั้น 3 สมมติว่าเผาด้วย P คงที่ จนได้ τ = F/P
  - ถ้า P ∝ F อายุจนถึงระดับตาย F_min จะเป็น τ = ln(F₀/F_min)/γ ไม่ใช่ F₀/P₀ = 1/γ
  - **τ = F/P จึงถูกเฉพาะกับระบบที่คุมอัตราเผาให้คงที่** (เช่นดาวที่ถูกคุมด้วย hydrostatic equilibrium) ไม่ใช่กับระบบที่ถูกหน่วงแบบ passive งาน A4 ต้องแก้จุดนี้

## A4: ต่อชั้น 2 → ชั้น 3 (2026-11-10)

`03_lanes/persistence/uet_layer2_to_3.py`, `test_layer2_to_3.py` (13 test)

**1. กฎอายุที่ถูกต้อง** มาจากชั้น 2 โดยตรง: dF/dt = −P(F) จึงได้ **τ = ∫ dF / P(F)** (จาก F_min ถึง F₀)

| ชนิดระบบ | กฎการเผา | อายุ |
|---|---|---|
| คุมอัตราเผา (ดาว) | P คงที่ | τ = F₀/P₀ ตรงกับชั้น 3 เดิม (ตรวจผ่านเส้นทางทั่วไป) |
| passive (ถูกหน่วง, A3) | P ∝ F | τ = (F₀/P₀) ln(F₀/F_min) |
| ทั่วไป | P ∝ Fⁿ | τ = F₀/(P₀(1−n)) · [1 − (F_min/F₀)^(1−n)] |

- การอินทิเกรตเชิงตัวเลขลู่เข้าหาสูตรปิด (error < 10⁻⁴) ทั้ง n = 0, 0.5, 1, 1.5
- **ระบบ passive ไม่มีวันถึง F = 0** อายุเพิ่มแบบ log เมื่อ F_min ลดลง "ตาย" จึงต้องนิยามด้วยระดับ F_min ที่โครงสร้างไม่นับว่ามีอยู่แล้ว ซึ่งเป็นพารามิเตอร์ใหม่ที่ต้องวัดแยก

**2. การคัดสรรยังอยู่** เมื่อใช้อายุคงที่จริง (ไม่ใช้การประมาณแบบตายสุ่ม) และผสมกฎการเผาสามแบบ:
ผู้ชนะคือ R* = 1/(aτ) ต่ำสุด pool นิ่งที่ R = 0.2674 เทียบ R* = 0.2670 (ต่าง 0.12% จากการปัด τ เป็นจำนวน step)
- กฎ F₀/P₀ แบบเดิมจัดให้ตัว passive แพ้ (1.25 เทียบ 2.0) แต่ตัว passive **ชนะจริง** เพราะ τ จริงคือ 3.74 กฎเดิมจึงทำนายผู้ชนะผิดเมื่อมีระบบ passive

**3. ข้อ 10 (Nash) `PARTIAL` → `MATCH` (ระดับโมเดล)**
- ทรัพยากรเดียว: ไม่มีดุลยภาพผสม ตัวเดียวชนะ

**4. บิตที่เขียน (B2)**

## R2: ระบบฟิสิกส์ที่ไม่มีชีวิตแต่สร้างตัวเองเพิ่มได้ (2026-11-10)

**เลเซอร์** เป็นระบบฟิสิกส์ที่ชั้น 3 ใช้ได้**ตรงทุกเทอม** (sympy identity):
- โฟตอนในแต่ละ mode สร้างโฟตอนเพิ่มด้วย stimulated emission ซึ่งเป็น autocatalytic
- ทุก mode แย่ง population inversion ร่วมกัน ซึ่งคือทรัพยากร R
- อายุของโฟตอน τ = พลังงานที่เก็บในโพรง ÷ กำลังที่รั่วออก ซึ่งตรงกับ τ = F/P

ผลที่ตามมา:
- R* ของชั้น 3 = **threshold inversion** N_th = 1/(Bτ) ในตำราเลเซอร์
- inversion ร่วมก้อนเดียว: **mode ที่ threshold ต่ำสุดชนะ ตัวอื่นดับ** และ inversion ถูกตรึงที่ threshold (gain clamping, ตรง 10⁻⁶) ซึ่งเป็นสิ่งที่วัดได้จริงในเลเซอร์ (single-mode lasing)
- inversion สองบริเวณ (spatial hole burning): **สอง mode อยู่ร่วมกัน** = ดุลยภาพผสมของ A4

**ผลต่อข้อ 5:** การคัดสรรด้วยการบริหารทรัพยากร "โดยไม่ต้องมีการเรียนรู้" เกิดในระบบฟิสิกส์จริงแล้ว เลเซอร์ไม่ได้เรียนรู้อะไร แต่ mode ที่ "ใช้ทรัพยากรคุ้มที่สุด" (threshold ต่ำสุด) คือตัวที่เหลืออยู่ ข้อ 5 จึงไม่ได้จำกัดอยู่แค่ในชีววิทยา
