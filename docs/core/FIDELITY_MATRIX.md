# Fidelity Matrix: ตรรกะของผู้เขียน เทียบกับสมการใน repo

> **Wave A1** ของแผน fidelity + falsification (2026-11-10) ร่างโดย agent: claude
> คำตัดสินทุกช่องเป็น **[ตีความโดย AI]** ผู้เขียนแก้ได้ ข้อที่ได้ CONTRADICTS ผู้เขียนต้องเลือกเองว่าจะแก้สมการหรือแก้ตรรกะ
> ที่มาของตรรกะ: [`AUTHOR_PROPOSITION.md`](AUTHOR_PROPOSITION.md) §1 ส่วนสถานะของสมการดูที่ [`THEORY_CARD.md`](THEORY_CARD.md)

| คำตัดสิน | ความหมาย |

| `MATCH` | สมการที่ derive แล้วพูดสิ่งเดียวกับตรรกะ |

## สรุป

- `MATCH` 1 ข้อ (5), `PARTIAL` 4 ข้อ (1, 2, 7, 10), `ASSUMED` 2 ข้อ (4, 8), `MISSING` 1 ข้อ (9), `CONTRADICTS` 1 ข้อ (3), `N/A` 1 ข้อ (6)
- **ชั้น 3 ตรงเจตนาที่สุด** แต่ตั้งอยู่บน τ = F/P ที่ยังเป็นสมมติฐาน
- **ชั้น 1 ตรงเจตนาแต่ส่วนใหญ่เป็น GR ที่มีอยู่แล้ว** ส่วนที่เป็นของ UET คือ ξ_c และ g_c
- **ชั้น 2 คือรอยต่อที่ขาด** ข้อ 1, 4 และ 8 รออยู่ที่นี่หมด เพราะยังไม่มี P = Tσ ที่คำนวณจากสนามจริง

## ข้อค้นพบระหว่างตรวจ (code review)

- `uet_covariant_open_system.derive_noise_kernel` คำนวณ `covariance` และ `expected` ด้วยสูตรเดียวกัน ทำให้ `kms_residual` เป็น 0 เสมอ จึงไม่ได้ทดสอบ KMS จริง
- `uet_covariant_balance.exchange_completed_ledger` ตั้ง `response_exchange = −matter_exchange` เอง ทำให้ `closure_max_abs` เป็น 0 เสมอ
- ทั้งสองจุดเป็น bookkeeping ตาม §6 ของ standard ไม่นับเป็น physics test **ไม่ได้แก้ในรอบนี้** เพราะ contract เดิมล็อกไฟล์ไว้ (AGENTS.md §6.2)
