# Correspondence contracts

This package contains standard-physics correspondence controls for the UET
parent contract. The current GR module accepts analytic tensor inputs and
checks declared identities; it does not compute curvature from a metric or
provide a curved-spacetime numerical solver.

Owner: FOUNDATION

The correspondence controls are standard-theory benchmarks and do not by
themselves establish a UET derivation, gauge-invariant observable, or GR
validation.
