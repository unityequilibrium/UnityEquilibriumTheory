# Ontology contracts

This package contains lane-specific mappings from declared lower-level fields
to collective coordinates. It records scale, frame, units, information loss,
and observable targets without identifying the distinct `C` lanes with one
universal physical quantity.

Owner: FOUNDATION

The coarse-graining implementation remains a candidate/internal contract. Its
mean-preservation and many-to-one checks do not establish microscopic closure,
covariant averaging, an RG flow, or SI observable calibration.
