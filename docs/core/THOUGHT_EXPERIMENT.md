## 1. ตัวทดลอง

อยู่บนยานอวกาศ มองเห็นเหตุการณ์ที่เกิดบนดาวดวงหนึ่งซึ่งอยู่ไกล สมมติว่าสิ่งที่เห็นกำลังเกิดอยู่ "ตอนนี้" แล้วบินไปหา แต่แสงที่เรารับใช้เวลาเดินทางหลายปี ระหว่างนั้นต้นทางเปลี่ยนไปแล้ว พอไปถึงเหตุการณ์นั้นอาจจบไปนานแล้ว

## 2. หลักการ (ไม่ขึ้นกับนิยามของ being/becoming)

**P1 [มาตรฐาน] สิ่งที่ผู้สังเกตวัดได้คือสถานะของต้นทางในอดีต**
ให้ระยะห่างเป็น r และสัญญาณเดินทางด้วยความเร็วจำกัด u เวลาหน่วงคือ τ = r/u เหตุการณ์ที่ต้นทางเวลา t_e ถูกรับเวลา t_o = t_e + τ และ

```
y(t_o) = O[ X_s(t_e) ] + η        ไม่ใช่   y(t_o) = O[ X_s(t_o) ]
```

**P2 [อนุมาน] ช่องว่างระหว่างบันทึกกับสถานะปัจจุบันของต้นทาง = อัตราการเปลี่ยน × อายุของบันทึก**
ถ้าผู้สังเกตถือว่าบันทึกคือปัจจุบัน จะผิดไปเท่ากับ

```
Δ(t) = X_s(t) − X_s(t_e)  ≈  Ẋ_s · a ,      a = t − t_e   (อายุของบันทึก, a ≥ τ)
```

ที่อันดับหนึ่ง สูตรนี้บอกว่าช่องว่างขึ้นกับสองอย่างเท่านั้น คือ **พฤติกรรมของต้นทาง (อัตราเปลี่ยน Ẋ_s)** และ**อายุของบันทึก (ซึ่งอย่างน้อยเท่ากับเวลาหน่วงที่มาจากระยะทาง)** ต้นทางที่นิ่ง (Ẋ_s = 0) ไม่มีช่องว่าง ถึงจะอยู่ไกล ส่วนต้นทางที่เปลี่ยนเร็วมีช่องว่างมาก
นี่คือรูปที่แม่นของความคิดที่ผู้เขียนพูดว่า "ระยะทางสัมพันธ์กับพฤติกรรมที่ทำให้ความจริงห่างออกไป" และเป็นสิ่งที่งานดาราศาสตร์ทำอยู่แล้ว เช่น การแก้ light-time ในตารางตำแหน่งดาวเคราะห์ **[มาตรฐาน]**

**P3 [มาตรฐาน] "ตอนนี้" ของที่อยู่ไกลไม่มีนิยามที่ผู้สังเกตทุกคนเห็นตรงกัน**
ตามสัมพัทธภาพ ความพร้อมกันของเหตุการณ์ที่อยู่ห่างกันขึ้นกับผู้สังเกต สิ่งที่ทุกคนเห็นตรงกันคือ**ความสัมพันธ์เชิงเหตุผล**: เหตุการณ์ A ส่งผลถึง B ได้ก็ต่อเมื่อ B อยู่ใน light cone อนาคตของ A

**P4 [ตีความโดย AI] "จริงร่วมกัน" เขียนเป็นนิยามเชิงปฏิบัติการได้โดยไม่ใช้คำว่า being**
ระบบ A และ B **มีบันทึกร่วมกัน** เมื่อเคยมีการสัมผัสเชิงเหตุผล (ตรง หรือผ่านต้นเหตุร่วมในอดีต) และข้อมูลของทั้งสองมีสหสัมพันธ์ I(A:B) > 0 ตัวนี้คือ mutual information ตัวเดียวกับที่คำนวณแล้วในงาน R3 (Σ = I + D) ดังนั้น "จริงร่วมกัน" ในที่นี้ไม่ได้กำหนดด้วยระยะห่าง ณ ปัจจุบัน แต่ด้วย**ประวัติการสัมผัสเชิงเหตุผล**บวกสหสัมพันธ์ที่เกิดขึ้นแล้ว

**แก้ไขจากผลทดสอบ O2 (2026-11-11):** ฉบับแรกของ v3 เขียนว่าสัมผัสเชิงเหตุผลหมายถึงอยู่ใน light cone ของกันและกัน (เวลา d/c) การทดสอบแสดงว่าแคบเกินไป สองระบบแบ่งปันบันทึกได้ตั้งแต่ **t ≥ d/(2c)** เพราะ past cone ของทั้งสองซ้อนกัน (ต้นเหตุร่วมอยู่กึ่งกลาง) ก่อนที่สัญญาณตรงจะมาถึง ก่อนเวลานั้นบันทึกร่วมน้อยมากแบบ super-exponential (1.5e-7, 2.7e-13, 0 ที่ระยะ 10, 20, 30) หลังจากนั้นเป็น 10⁻³ ถึง 10⁻² nats ดู `docs/standard/results/R_O2_SHARED_RECORD_CONE.json`

**ผลจากโมเดลที่ตรวจแล้ว [อนุมาน]:** "เกิดขึ้นแล้ว" ไม่ได้แปลว่า "อ่านกลับได้ตลอดไป" ในระบบปิดของ R3 (โมเดล Gaussian คลาสสิกแบบง่าย) entropy รวมคงที่ (ผิดพลาดราว 10⁻¹⁰) แต่บันทึกที่อ่านกลับได้ I ลดจากราว 0.87 เหลือราว 0.24 nats ระหว่างเวลา 2 ถึง 40 ขณะที่ความต่างศักย์ D เพิ่มขึ้น ดู `docs/standard/results/R_R3_TRACE_DECOMPOSITION.json` กล่าวคือข้อมูลไม่หายไปจากระบบรวม แต่กระจายเป็นสหสัมพันธ์ที่เข้าถึงจากที่ใดที่หนึ่งไม่ได้อีก จึงยิ่งไม่ควรอ้างว่าสิ่งที่เกิดแล้วเป็นนิรันดร์ในความหมายของการอ่านได้

## 4. สิ่งที่ตัดออกจาก v1/v2 และเหตุผล

| ข้อความเดิม | การจัดการ | เหตุผล |
|---|---|---|
| สิ่งที่เกิดขึ้นไปแล้วคือ being (คงอยู่นิรันดร์) | **ตัด** แทนด้วย "เกิดขึ้นแล้ว + มีบันทึก" | ฟิสิกส์ไม่ตัดสินว่าอดีตคงอยู่นิรันดร์หรือไม่ (eternalism, presentism และ growing block เป็นการตีความ ไม่ใช่ผลของสมการ) |
| จักรวาลไม่มี being มีแค่ becoming | **ย้ายเป็นการตีความ** ห้ามใช้เป็นข้อสรุป | ไม่มีสมการหรือการทดลองรองรับ และการอ่านแบบ block universe ของสัมพัทธภาพทั่วไปยังเปิดอยู่ |
| การคำนวณของเราทำให้มันเปลี่ยน | **ตัด** | การรับแสงที่ปล่อยไปแล้วไม่ส่งผลย้อนกลับถึงเหตุการณ์ต้นทางตามหลักเหตุผล (causality) กรณีวัดแบบควอนตัมเป็นประเด็นแยก ไม่ใช้ thought experiment นี้อ้าง |
| สิ่งที่เห็นไม่ใช่ความจริง | **แทนด้วย** "เป็นบันทึกจริงของอดีต แต่ไม่ใช่สถานะปัจจุบันของต้นทาง" | ตัวบันทึกเป็นข้อเท็จจริงทางกายภาพ ที่ผิดคือการถือมันเป็นปัจจุบัน |
| ระยะทางทำให้เราจริงร่วมกันได้หรือไม่ได้ | **แทนด้วย P2 และ P4** | พูดตรง ๆ ไม่ได้ ที่พูดได้คือช่องว่างเท่ากับอัตราเปลี่ยนคูณอายุบันทึก และบันทึกร่วมต้องมีการสัมผัสเชิงเหตุผล |
| space เป็นที่ทิ้งร่องรอยของทุกพฤติกรรม | **คงเป็นสมมติฐาน UET** | ช่องแรงโน้มถ่วงมีหลักฐาน L2 (T006) แต่ร่องรอยส่วนใหญ่เป็นความต่างศักย์ D ไม่ใช่ข้อมูลที่อ่านกลับ (R3) |
| ไอน์สไตน์เป็นกรณีเฉพาะของกรอบกว้าง | **ไม่ derive ในเอกสารนี้** | ใช้แค่ P3 เป็นจุดเชื่อม ส่วนที่เหลือของ v2 ข้อ 11–12 เป็นประวัติ |
