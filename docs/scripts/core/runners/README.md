# 🏃 Runners Scripts

Executors for running tests at various scopes (Topic, System, All).

## 📋 Script Inventory

| Script | Purpose | Run Command |
| :--- | :--- | :--- |
| `run_topic_tests.py` | **Topic Runner**: Runs all tests for a specific Topic ID (e.g., 0.1). | `python docs/scripts/Runners/run_topic_tests.py` |
